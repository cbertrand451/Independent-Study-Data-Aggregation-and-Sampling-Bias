# Missing Data Analysis

## Summary

These notebooks explore how missing data and data quality flags can affect analysis results. They focus on deciding which records to keep, how missingness is distributed, and how different missing data scenarios can change conclusions.

- *06_data_quality_filtering.ipynb*: uses note fields as quality flags and compares results before and after filtering.
- *07_missingness_simulation_scenarios.ipynb*: simulates different missing data patterns to show how missingness can affect summaries and trends.

## Recommended Order

Start with *06_data_quality_filtering.ipynb*, then move to *07_missingness_simulation_scenarios.ipynb*.

The notebooks can be explored independently, but the recommended order is useful because the first notebook introduces how the dataset records data-quality issues, while the second expands that idea into broader missing-data scenarios.
