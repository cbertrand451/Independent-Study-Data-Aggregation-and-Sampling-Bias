# Sampling Bias

## Summary

These notebooks explore how sampling choices can affect representation in the dataset and the results that follow from it. They compare regular random sampling with stratified sampling, then carry those choices into a model-preparation workflow.

- *04_stratified_sampling.ipynb*: compares random samples and stratified samples, with a focus on species representation.
- *05_machine_learning_preparation.ipynb*: uses the sampling comparison to prepare datasets for machine-learning-style analysis and checks how sampling affects model inputs and targets.

## Recommended Order

Start with *04_stratified_sampling.ipynb*, then move to *05_machine_learning_preparation.ipynb*.

These notebooks should be explored in order. The second notebook builds on the sampling ideas from the first, so it will make the most sense after seeing how random and stratified samples differ.
