# Aggregation Analysis

## Summary

These notebooks explore how changing the level of aggregation can change the patterns that appear in the Portal rodent data. They focus on taxonomic grouping, time grouping, and summary statistics.

- *01_population_trends.ipynb*: compares population patterns at the species and genus levels.
- *02_monthly_vs_yearly.ipynb*: shows how monthly and yearly summaries can emphasize different trends.
- *03_mean_vs_median_weight.ipynb*: compares mean and median weight summaries across aggregation levels.

## Recommended Order

Start with *01_population_trends.ipynb*, then move to *02_monthly_vs_yearly.ipynb*, and finish with *03_mean_vs_median_weight.ipynb*.

The notebooks can also be explored independently. Reading them in order is recommended because each one adds another example of how reasonable aggregation choices can affect analysis results.
