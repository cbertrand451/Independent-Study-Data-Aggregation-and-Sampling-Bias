# Notebook Lessons

This folder holds the notebooks which serve as lessons for the project. It is reccomended to go in this order:

1. *aggregation_analysis*: learn how grouping data into specific domains will result in different statistical outputs
2. *sampling_bias*: explore how drawing data from different sources or groups will result in different analysis
3. *missing_data_analysis*: explore how missing data can affect results, and discover different scenarios where missing data can have larger/smaller impacts
