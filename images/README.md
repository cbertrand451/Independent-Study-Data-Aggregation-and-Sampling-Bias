# Images

This folder contains all of the generated images that are used throughout the notebooks, as part of the lesson. The images all come from the *plots.ipynb* notebook. This notebook uses the same data wrangnling processes used in the lessons, and creates visuals based on the computational results found in the notebooks. The images are then displayed statically in the notebooks. 

Images are named based on the lesson they correlated to. For example

- *fig_1_1.png*: first figure in the *01_population_trends.ipynb* notebook

Figures go all the way from lesson 1 to lesson 7.
